### 💻 Descripción general del sistema
TicketsOut es un Sistema de Gestión Simple desarrollado como aplicación web para
facilitar la organización interna de una empresa o equipo de trabajo

---

El sistema permitirá:
- 🎫 **Registro de tickets de incidencias**
  Los usuarios podrán reportar problemas técnicos, fallos o solicitudes internas
- 📊 **Seguimiento del estado de los tickets**
  Cada ticket podrá tener estados como:
  - Abierto
  - En proceso
  - Resuelto
  - Cerrado
- 📅 **Gestión organizada de incidencia**
  Visualización estructurada de los tickets para facilitar su administración

---

### 🛠 Tecnologías utilizadas (Frontend)

El Frontend del sistema está desarrollado con:

- Angular
- TypeScript
- Bootstrap

---

### 🎯 Objetivo del proyecto

Desarrollar una aplicación web funcional que permita administrar tickets de incidencias empresariales aplicando la
metodología Scrum, garantizando organización, trazabilidad y control en la gestión de problemas internos
